## Destination

Buildable spec of a Windows app (WPF .NET 8) with full Copyous parity — types, pins, tags, actions, shortcuts, settings, style + a system tray button — ready for `to-spec`.

## Notes

- Stack locked: **C# WPF (.NET 8)**. Solo Windows-only, no shim.
- Default hotkeys: **open `Ctrl+Shift+V`**, **incognito `Ctrl+Shift+Alt+V`**, configurable. `Win+V` / `Win+Shift+V` out (reserved by the OS).
- Tray: click opens the popup; menu = `Open / Incognito / Clear (keep pins+tags) / Settings / Exit`.
- Distribution: **portable single-file + Inno Setup installer** (MSIX later). Autostart via the `Run` key. Single-instance via a named `Mutex`. Target **Win10 20H2+ / Win11**.
- Linux→Windows equivalence map locked: `Libgda→Microsoft.Data.Sqlite`, `GSound→System.Media`, `DBus→tray+CLI/local named-pipe`, `Soup→HttpClient`, `hljs→local highlight`, `virtual paste→SendInput`, `GSettings→local JSON`, `nautilus/xdg-open→ShellExecute`.
- License: **GPL-3.0-or-later** (same as the original).
- Skills per ticket: `grilling` + `domain-modeling` on every HITL; `research` via subagent on AFK; `prototype` for UI/behavior questions.
- Tracker: local markdown. Frontier = open, unblocked, unclaimed `issues/`. `Status: claimed` before working; `Status: resolved` + `## Answer` when resolving.
- Original source: https://github.com/boerdereinar/copyous (8 types: Text, Code, Image, File, Files, Link, Character, Color; DB v2; 9 tags; actions.json; 4 prefs pages; DBus Toggle/Show/Hide/ClearHistory).
